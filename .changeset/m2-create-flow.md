Create your first mod: describe a change in the side panel, optionally pick an element on the
page, generate it with your own model provider, preview it on the current tab, then keep or
discard it. Provider settings (Ollama, LM Studio, OpenRouter, OpenAI or the Anthropic API) live
in the options page, with a connection test that explains how to fix common setup problems.
