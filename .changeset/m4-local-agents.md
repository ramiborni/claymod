Create and repair mods with an agent CLI you already use: Claude Code, Codex, Gemini CLI or
Antigravity CLI, through the new optional `claymod-bridge` app. Choose Local agent in settings,
run the install command it shows, and pick the CLI's own sign-in or an API key kept in your
system keychain. Google's CLIs default to an API key, with a clear warning before using their
sign-in. Provider API keys saved in Claymod are now encrypted in the browser.
