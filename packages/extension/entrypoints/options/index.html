Agents (MCP)

Let an AI agent you already use (Claude Code, Codex, OpenCode…) read the page you have open and propose mods. You approve every preview and save in Claymod's side panel. Needs claymod-bridge.

Add Claymod to your agent

Claude Code:

claude mcp add claymod -- claymod-bridge mcp

Codex (allow time for your approval):

codex mcp add claymod -- claymod-bridge mcp Then set tool_timeout_sec = 180 under [mcp_servers.claymod] in ~/.codex/config.toml.

OpenCode (opencode.json):

{"mcp": {"servers": {"claymod": {"type": "local", "command": ["claymod-bridge", "mcp"]}}}}
